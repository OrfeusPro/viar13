## ADM-AUD-11-CACHE — реализовано и проверено локально

Оригинал: `C:/OSPanel/domains/asoft/viar/app/Http/Controllers/Admin/VoyagerAdminController.php`, методы `cache_clear` / `cache_set`; routes/admin.php. Команды: `cache:clear` и последовательность `config:cache`, `route:cache`. Более широкая `optimize:clear` не используется.

Новая страница: `/filament/cache-tools`, `app/Filament/Pages/CacheTools.php`. Существующий пункт «Инструменты → Очистка кеша» ведёт на неё через BreadMenuTree. В отличие от старой GET-ссылки, открытие страницы ничего не очищает: выполнение только кнопкой Livewire. Новые таблицы/права/миграции не нужны.

Используется существующее право `browse_compass` оригинального служебного инструмента. Право проверяется при mount/hydrate и непосредственно перед выполнением. Доступны только операции clear/build, произвольные команды и аргументы не принимаются. Кнопки блокируются на время запроса. Успех показывается уведомлением; при отказе сообщается конкретная команда и уже выполненная часть, последующие команды не запускаются. В лог попадают только имя команды, exit code и класс исключения; output/exception message не публикуются из-за возможных секретов конфигурации.
